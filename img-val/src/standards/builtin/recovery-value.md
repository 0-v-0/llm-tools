# 个人图片恢复价值估值标准

## 1. 评分维度与权重

本标准的估值基准是"困难假设"：假设该图片已丢失，评估者为找回它愿意付出的最大成本（含专业恢复服务、时间、交易等价物）。总评分 = 各维度加权得分。

| 维度         | 权重 | 0 分（丢得起）      | 5 分（丢不起）               |
| ------------ | ---- | ------------------- | ------------------------- |
| 不可替代性   | 0.30 | 可重新获取/随处可得 | 独一无二，无处可补           |
| 情感纪念价值 | 0.25 | 无关紧要的随手拍    | 婚礼/新生儿/人生里程碑       |
| 时效稀缺度   | 0.20 | 随时可重拍          | 一次性事件/已逝场景/历史瞬间 |
| 内容完整度   | 0.15 | 形同虚设/大面积缺失 | 关键内容完整、含珍贵细节     |
| 可传播性     | 0.10 | 无分享价值          | 适合转发/收藏/讨论           |

每项 0–5 分，加权得分 = Σ(维度分 × 权重)，范围 0–5。得分越高，丢失后损失越大、恢复意愿越强。

## 2. 子类别参考基准

在应用区间前先判断子类别，用于校准"情感纪念价值"与"不可替代性"：

### 截图类（系统截图、应用界面、聊天记录）
- 基准加分：含重要信息/仅此一份的记录 +1，涉及账务/证件的关键截图 +1
- 基准减分：网络可重新下载/随处可补的功能截图 -1

### 表情包/梗图类
- 基准加分：原创/个人定制/带私密互动内容（如朋友专属梗）+1
- 基准减分：全网公开流通的热门表情，随时可得 -1

### 美食/生活记录类
- 基准加分：特殊场合记录（老友聚会/告别聚餐）+1，手作/独门配方成品 +1
- 基准减分：普通日常随手拍、可随时重做 -1

### 游戏截图/战绩类
- 基准加分：稀有成就/绝版活动/已停服游戏截图 +1
- 基准减分：普通关卡/通用界面，随处可见 -1

### 二次元/同人创作类
- 基准加分：原创独特插画、仅此一份 +1，私信/私下赠予的精修图 +1
- 基准减分：低分辨率截图、公开发布可再下载 -1

### 萌宠/动物照片类
- 基准加分：宠物成长记录/已故宠物唯一留影 +1
- 基准减分：模糊/普通记录，可随时重拍 -1

## 3. 最高愿意花费的恢复成本区间 (￥)

| 加权得分 | 下限     | 上限   | 说明                   |
| -------- | -------- | ------ | ---------------------- |
| 0.0–1.0  | 0        | 10     | 丢得起，不值得专门找回 |
| 1.0–2.0  | 10.01    | 50     | 小有遗憾、偶尔会想起   |
| 2.0–3.0  | 50.01    | 200    | 值得一试数据恢复/检索  |
| 3.0–4.0  | 200.01   | 1000   | 会认真花钱/花时间找回  |
| 4.0–4.5  | 1000.01  | 10000  | 高价值纪念，愿专业服务 |
| 4.5–5.0  | 10000.01 | 100000 | 罕见历史记录，不惜代价 |

## 4. 修正因子（仅供参考）

- 历史事件截图（如重大新闻、绝版活动截图）：×1.5
- 图片损坏或部分解码：×0.5 并将 confidence 标为 low
- 已过时消息：×0.2
- 涉诉证据、公证文件：×1.5
- 含敏感内容（涉政/暴力等）：×0.4

## 5. 输出约束

- min_value：客观假设下的估值，即图片对大多数人的价值，可能无意义、可丢弃（如照片中是陌生人、随手截的无用图），对应区间下限
- max_value：最好假设下的估值，即图片可能承载重大情感或数据价值、难以替代（如照片中是至亲且是最后一张留影），对应区间上限
- min_value / max_value 可保留小数，精度0.01
- rationale 须指明图片类型（子类别）、加权得分估算、修正因子
- confidence: high 仅当图片清晰且维度可判断并明确知道是否丢失；medium 当 1–2 维度存疑或丢失状态未知；low 当图片损坏、题材无法确认或纯属推测
